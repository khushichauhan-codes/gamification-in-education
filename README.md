# Gamification in Education

## Project Overview
Gamification in Education is a web-based learning platform designed to make learning more interactive and engaging through quizzes, rewards, and progress tracking.

## Features
- Branch-wise and Semester-wise subject selection
- Topic-based quizzes
- Students must complete the current quiz before moving to the next level
- Reward system for motivation
- Progress tracking
- User-friendly interface

## Technologies Used
- HTML
- CSS
- JavaScript
